# Menu Principal  
Ventana que contiene una tabla con todos los estudiantes dentro de la 
base de datos, botones para agregar, eliminar y editar estudiantes, y un 
buscador. Además, permite ordenar la forma en la que se muestran los 
estudiantes dentro de la tabla, permitiéndole al usuario escoger entre 
orden alfabético, por matrícula o edad.  
##Contenido  
* Tabla de estudiantes.
* Agregar estudiantes.
* Eliminar estudiantes.
* Editar estudiantes.
* Buscar estudianes.
* Ordenar lista de estudiantes.
